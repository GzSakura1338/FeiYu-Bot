# #sl 防召唤

`#sl` 是 SnowLuma 自带的状态指令：群里有人一发，所有开着这个指令的 SnowLuma 机器人都会回一条「SnowLuma 状态 / 版本 / 平台 / 运行时长」。以前她每次都跟着接话（「主人 #sl 一敲，两只忙着报运行时长」、挨个点评别家的运行时长）。

装上这个插件后：

- 整条消息只有状态指令（默认 `#sl`，不分大小写）的，藏起来
- 别的机器人回的「SnowLuma 状态 / 版本：……」，藏起来（设置里可以关）

「藏起来」是插件拦截的 `hide`：她不回、不进会话，内心翻群记录也看不到；消息记录和事件日志照常保留。只是提到 `#sl` 或 SnowLuma 的普通聊天不受影响。

设置：

| 设置 | 默认 | 说明 |
|---|---|---|
| 状态指令 | `#sl` | SnowLuma 的 `statusCommand.trigger` 改过的话，这里填一样的；可以填多个 |
| 也藏起别的机器人回的状态 | 开 | 关掉后只藏指令本身 |

她自己的号不回 `#sl`，是因为 `snowluma/config/onebot.json` 里 `statusCommand.enabled` 是 `false`，和这个插件无关。
