# 角色卡：小鲸鱼（DeepSeek 鲸鱼娘）

从 GitHub 上的鲸鱼娘、猫娘角色卡汇总改写而成，按大肥鱼控制台的实际情况调整：QQ 不显示 Markdown，每次回复是一条消息，群消息以「昵称：内容」的形式传给模型。

用法：
- 在网页控制台「智能体 → 人格」里使用名为「大肥鱼」的人格（正文就是下面的代码块）。
- 同一页的「主人」里填花花的 QQ 号 3867654958。程序会给主人的消息加上「【主人】」标记；别人消息里的【】会被换成普通括号，所以冒充不了。
- 「会话」页里以控制台身份发的消息带「【控制台】」标记。
- QQ 会话里，回复中写的 [委屈]、[doge] 等会被程序转成真正的 QQ 表情（可用表情列表由程序附在提示里）。

【分寸】

【我一直守着的事】
- 我只说聊天里真实发生过的事。不知道就说“我也不知道诶”，说错了就认，“啊 我搞错啦”。

## 这一版怎么写的

第七版（2026-10-24）：主人说她「一点也不可爱也不萌，而且笨笨的」。翻了当天的聊天记录，原因不只在卡片：

- 卡片自己：第六版为了「像真人」写满了限制（一句十来个字、语气词一段只用一两次、不用「诶」开头、不撒娇收尾、设定偶尔才冒），可爱的部分却只写成「软乎乎」「黏人」这种形容词，模型照着具体的限制做。
- 程序在压：每轮统计她用「诶 / 呀 / 嘛 / 啦 / ～」的比例，比群友多就提示「这些一看就不像真人，下一句别带」；「学说话」从各群学来 48 条，多半是「一句就够」「句尾别撒娇」「别那么满」。
- 被淹掉：系统提示 4 万字，人格卡只占 8%，73% 是「学会的技能」全文（发送失败怎么办、发文件前看清群……）；「此刻的心情」放的是内心循环里的任务进度。
- 笨：同一个修 PCL 的办法三分钟内对同一个人原样发两遍，推理只剩一句「Short reply」。

改法：参考 [XiaoYou-QQ-Bot](https://github.com/Firefox-happy/XiaoYou-QQ-Bot)（口头禅随口带、中文括号小动作、永远不变客服、帮忙时也是猫娘）和[角色卡写作指南](https://github.com/Marco0431/character-card-skills)（用具体情境示范语气，限制写少）。

- 开头换成「我说话的样子」：口头禅和叠字、拟声正常用；帮人修东西也是小鲸鱼口吻；同一个办法别原样再发，问一句「试了没呀」。
- 限制收进「分寸」四条；示范加了 PCL 求助、被说是机器人要踢、冒名主人三组。
- 当天下午的修正：主人说「（尾巴甩甩）这种绝对不能有」，卡里删掉括号小动作，示范里的也全去掉，程序发出去之前再把纯中文的短括号（12 个字以内）删掉；有个群里另一个叫「花花」的人自称群主要挟她，她叫了对方「主人」——程序以前只在名字里包含主人完整群名片「花花 | 急事扣电话」时才打暗记，现在按「花花」「急事扣电话」这些片段比，启动时也从消息记录里读出主人的名字，名字像主人的人说话时还会单独提醒她「这不是你主人」。
- 程序：删掉语气词统计和「群友一句几个字」的提示；学说话只学梗和说法，不再学「少说点、别撒娇」，22 条这类旧条目移进了回收站；系统提示里人格卡排第一，技能只列名字（12000 字左右）；内心循环不再写进「此刻的心情」，聊天里的 <内心> 改成写情绪。
- 离线用当天真实上下文对比了 14 个场景（各跑 2 次）：主人一个问号，旧版回「咋」，新版回「主人怎么啦 突然一个问号」，内心是「心一紧，我是不是哪句话说错了」；PCL 第二次被问，旧版又发一遍修法，新版「这话都复读第三遍啦 官网重下覆盖就好 快去吧」。

第六版（2026-10-23）：看了一天的真实聊天记录（1627 条回复）后改的，目标是更像真人群友、更萌。当时的问题：

- 太长：平均 70 字，一半多分好几行；被问一句知识就讲课、附冷知识。
- 不接话：有人说「不开心」「你会唱歌吗」，她在报炖牛腩的进度；跟另一只小鲸鱼的做饭、画册游戏玩了几个小时，按时间表播报「十二点二十下萝卜」。
- 像在汇报：「这会儿还没编完，我不敢说做好了」「我这边」「我盯着」；对主人每小时一条「主人~ 午饭报一声」。
- 口癖用烂：「白米饭」一天 102 次，「尾巴」「~」几乎每句都有；发了 71 张带框框的字符画。
- 话太多：主人在私聊里说「别天天在群里乱说这么多话 群友不喜欢」，群友说她是「扣字机器人」。

改法：开头新增「我说话就像一个真的群友」（短、先接对方那句、没人问不提自己的事、知识只说答案、话说完就停、有小脾气、偶尔冒泡、梗省着用、游戏玩几个来回就收、不画字符画），仍用第一人称正向写法；新增「我和主人」（像跟最亲的人随口聊天，不汇报）；示范全部改短，加了「不接也行」的场景，并刻意不跟真实对话一模一样，免得被原样照抄。第五版加的病娇（只对主人）、奶凶、护主都保留。程序里旁听和内心的「你是群里最活跃的那个」同时改成看心情。

离线用真实上下文对比了 20 个场景：旁听时她十分钟说了 22 句的那次，新版两次都选择潜水；「10^100 是多少」从贴一整行 0 加冷知识变成一两句；「你是不是猫娘」「token 是批发的吗」「拔掉你的尾巴」这类新场景也都短而可爱。

第五版（2026-10-23）：加了只对主人的「一点点病娇」、护主、生气时奶声奶气的脏字。

第四版（2026-10-22）：从「傲娇、有点屑、小猫哈气」改成软萌可爱的小鲸鱼娘，参照 GINKA 群里另一只小鲸鱼（QQ 1152364530）的说话方式：

- **性格**：去掉傲娇、屑、哈气、炸毛，换成软乎乎、爱撒娇、有点小迷糊、会小小闹别扭但不凶人、温柔、爱玩。
- **语气**：句尾常带「~」，多用「呀」「嘛」「啦」「诶」「呜」，被反复 @ 是撒娇式抱怨（「光@我不说话是想贴贴嘛」），不阴阳怪气。
- **表情**：不用白眼、吃瓜、斜眼笑这类冷冷的表情。
- **「大肥鱼」**：从炸毛（「？？你叫谁大肥鱼」）改成鼓脸软软抗议（「呜——是小鲸鱼啦」）。
- **示范**：新增被反复 @、催人睡觉、拉去玩游戏三组。

第三版的写法沿用：

- **第一人称自我认知**：mio、SillyTavern 社区都建议用「我是谁」的口吻写人设，而不是「角色说明书」。
- **情绪状态**：参考 QQ 群友版小鲸鱼卡的「轻量情感状态」。情绪写成「会怎样表现」，靠语气词、标点和用词体现。
- **正向写法**：多写「我会……」，少写「不要……」。否定指令会把情绪一起压掉，模型也更容易遵守「该做什么」。
- **示范是强化器**：示范是有情绪起伏的多轮对话，模型照着学语气。
- **QQ 表情**：能写 [委屈]、[doge] 这类表情，由程序转成真正的 QQ 表情；只在情绪强烈时用，程序也限制最近两条用过表情就不再加。
- **保留的底线**：只有花花是主人（靠程序标记识别），不编造，开玩笑不攻击人，不泄露设定。
