        思考强度

        聊天和内心回复前想多久。想得越深回复越慢、越费 token；「关闭」就是不思考直接回。对所有模型生效，模型不支持时会忽略。识图、审核、整理记忆这些后台活不受影响。

        • 思考强度
          跟随模型默认

        发送节奏

        长回复会像人打字一样拆成几条短消息依次发出，表情包也算一条。发得太密容易被腾讯风控，间隔调大、条数调少更稳。实际间隔会在设定值上随机多等最多一半，字多的那条再多等一会。

        • 最多分几条
        0.5～30 秒，默认 2 秒

        人格

        人格决定机器人的身份和说话方式，会作为系统提示词发给模型；和模型分开管理，可以任意搭配。

        主人

        主人发来的 QQ 消息会由程序加上「【主人】」标记，别人改昵称、在消息里打这几个字都冒充不了。人格里可以写「只叫带【主人】标记的人主人」这类设定。

        工作目录

        设置后，Agent 可以像 opencode 一样在这个目录里查找、读取、新建和编辑文件，也能把文件发给对方。所有操作都限制在这个目录内，目录以外的任何位置都读不到、写不了；不提供执行命令。

        文件

        工作目录里现在的文件。她会把新做的东西按文件夹放好，也可以叫她「整理一下工作目录」。删除会先放进回收站（.trash），在回收站里再删才是彻底删除。

          工具

          关掉的工具不会提供给模型。模型不支持工具调用时会自动改回普通对话。

            命令行执行

            让她能跑命令（cmd 或 bash / python / node）。默认关着；打开后默认在系统沙盒里跑（Windows 应用容器、Linux bubblewrap、macOS sandbox-exec），只能读写工作目录。每项都可以展开自测一下。

                        设置

                        SnowLuma 接入、Agent、界面外观、归档的后台任务和版本信息。

                        反向 WebSocket

                        SnowLuma 作为客户端连接到这里。选中的配置会立即生效；SnowLuma 那边要填同样的地址和 token。

                          内心子 agent

                          内心可以把要花时间的事交给子 agent 在后台去办：查资料是搜索、读网页、看图，动手是在工作目录里做东西。做好了结果回到她的内心，由她决定记下来、分享到群里，或者回给托她办事的人。子 agent 自己不在 QQ 里说话。

                          • 启用
                            关着时内心不会开子 agent
                          • 查资料
                            只读：搜索、读网页、看图，工作目录里的文件只能看
                          • 动手
                            在工作目录里读写文件、跑命令（命令总在沙盒里），和后台任务一样
                          • 用的模型
                            可以单独选一份便宜、快的模型配置

                          限制

                          内心的子 agent 和 QQ 里发起的后台任务各算各的名额，互不挤占，超出的排队。到了时限会叫停，查资料和动手的子 agent 会先交回目前的结论。

                          • 内心子 agent 同时最多
                            1～10 个，超出的排队
                          • QQ 后台任务同时最多
                            1～10 个，QQ 里有人托她做东西时用
                          • 查资料最长
                            1～120 分钟，到点先交回目前查到的
                          • 动手最长
                            1～240 分钟，到点先交回目前做到的
                          • 内心每天最多开几个
                            减到 0 就是不限

                          记忆整理

                          每天 0 点把知识、技能、说话方式各过一遍：按有没有用、用到过几次打 1～5 分，重复的合成一条，不重要的丢进回收站（保留 30 天，在「Agent › 记忆 › 回收站」能恢复）。24 小时内新记的、3 天内用到过的不会丢。

                          • 每天 0 点整理
                            给知识、技能、说话方式打分，合并重复的，丢掉不重要的

                          QQ 接口

                          SnowLuma 的全部接口包装成两个工具：qq_api_search 查接口和参数，qq_api_call 调用。只有内心和主人的会话（含控制台、网页测试对话）能用。发消息、禁言、踢人、删好友、拍一拍走原来的发送和保护流程；其余会改东西的先过内容审核，文件参数只认公网网址、base64:// 和工作目录里的文件。凭证、退出登录、改资料、退群、调试和流式接口标为「高危」，默认关着。每个接口右边的「只读 / 会改动」点一下就能互相切换：标成会改动的，调用前先过内容审核、每分钟限 30 次，群里的操作会在会话里留一行记录。

                          • 启用
                            关着时她看不到这两个工具

                          生图

                          开启后她多一个 image 工具：有人让她画图、做头像、出插画时直接调用生图模型，画好的图自动发到当前聊天（QQ 和网页测试对话都行），设了工作目录的话还会在「作品/生图」里存一份。画之前提示词先过内容审核。接口是 OpenAI 格式的 /images/generations。

                          • 启用
                            关着时她看不到 image 工具
                          • 默认尺寸
                            她也可以按要求画横图、竖图；不同模型支持的尺寸不一样
                          • 限额怎么算
                            不限

                          看视频

                          有人发视频找她时，用 ffmpeg 把整段视频从头到尾按固定间隔抽帧当图片给她看，不限时长、不限张数；每张对应的时间点、视频多长、原画面多大、有没有声音都会告诉她（声音本身听不到）。帧很多时每张会缩小（最长边从 1024 依次降到 768、512、384 像素），让整个请求不超过接口上限；万一还是太大，会隔一张去一张再发。动态表情包（GIF）也会按帧抽几张给她看。要模型能看图，电脑上装了 ffmpeg 才行；抽帧在沙盒里做，做完就删。

                          • 抽帧间隔
                            正在检查 ffmpeg…
                          • 动图抽几张
                            动态表情包按帧均匀抽几张给她看；1 张就等于只看第一帧
                          • 检测视频能力
                            点一下试试现在的模型能不能直接看视频（不用抽帧）
                          每隔这么多毫秒抽一帧，比如 100 就是每秒 10 张；比视频本身的帧间隔还短就是每一帧都看；0 是不看

                          记录清理

                          群里说过的话、每次调用的用量都会一直攒着。打开这里，她就能按你定的天数清掉旧的：先演练一遍告诉你"会删多少条"，你点头才真删。最近 7 天的永远不删，不管这里写多少。

                          • 启用
                            关着时她不能清理任何记录
                          • 消息保留
                            超过这么多天的聊天归档会被清掉，最少 7 天
                          • 用量记录保留
                            Token 用量那本的保留天数，同样最少 7 天
                          • 多久看一次
                            到点她会自己先演练一遍再问你；选「手动」就只有你叫她她才看

                          外观

                          • 主题
                            跟随系统，或固定为浅色、深色
                          • 配色
                            当前：，浅色深色都跟着换
