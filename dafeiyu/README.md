# FeiYu Bot

自己实现的 QQ 机器人控制台（代码里的包名和目录名仍叫 dafeiyu）（Java 25 + Gradle），前端按 m3.material.io 的 Material Design 3 风格设计。
负责连接 NapCat、记录消息，并用大模型在 QQ 里自动回复（智能体部分对齐 opencode 的实现）。

## 运行

- 双击上一级目录的 `start-dafeiyu.bat`，或者在本目录执行 `.\gradlew.bat run`
- 打开网页控制台：http://127.0.0.1:8090/
- `config.properties`：控制台端口、前端目录、数据库位置，以及反向 WebSocket 的初始默认值
- 其余配置都在网页上管理，存在 SQLite 数据库 `data/dafeiyu.db`（含 API Key，已加入 .gitignore）

**改前端不用重启**：`web.dir`（默认 `src/main/resources/web`）存在时，后端每次请求都直接读这个目录，改完刷新浏览器即可。改 Java 代码需要重启。

**注释**：项目不写注释，改完运行 `python scripts/strip-comments.py`（`--check` 只检查）。

## 智能体

- 网页「智能体」分七个子页：模型 / 人格 / 工作目录 / 会话 / 内心 / 记忆 / 表情包（地址 `#agent/models`、`#agent/personas`、`#agent/workspace`、`#agent/sessions`、`#agent/mind`、`#agent/memory`、`#agent/stickers`；旧的 `#agent/chat` 跳到会话）
- 会话：QQ 私聊、群聊和网页测试对话在同一个列表里，正在回复的实时显示生成过程、工具调用和她的「内心」；可以停止回复
  - QQ 会话：以控制台身份发消息（回复可选是否发到 QQ，消息带「【控制台】」标记）
  - 「新对话」建一个网页测试对话（`web:` 开头，重启后保留，标题取第一句话）：可以粘贴 / 拖入图片，头部切换人格和模型，发送的文件直接显示下载
- 命令（只在网页控制台可用，QQ 里发 / 开头的消息只是普通聊天）：`/clear` 清空上下文、`/compact` 立即压缩上下文、`/stop` 停止回复、`/status` 会话状态、`/say` 以机器人身份直接发到 QQ（不经过模型）、`/reflect` 立即回顾这个会话更新记忆、`/help`
- 主人：「人格」页填主人的 QQ 号后，主人的消息由程序加上「【主人】」标记；其他人消息和昵称里的【】会被换成普通括号，冒充不了
- 防认错人（群里）：
  - 一条群消息里的换行显示成「 / 」，伪造不出「花花：……」这样的假行；昵称里的冒号和换行也会去掉
  - 和别人重名、和主人重名、和机器人自己重名（唤醒词 / QQ 昵称）、名字里带「主人」的，昵称后面加「#QQ 尾号」区分；主人永远用原名
  - 群里出现和她重名的人或机器人时，每轮额外提醒「XX#1234 是和你重名的别人」；它 @ 她、回复她都不算叫她，只当普通群聊看心情接
  - 发出去的消息里 `#尾号` 会去掉，写「@昵称#尾号」会 @ 到对应的人
- 心情和内心：QQ 会话里模型每次回复先写一句 `<内心>…</内心>`（不发到 QQ，存在记录里，网页上显示成「内心」），程序把它当作她此刻的心情，下次回复时连同当前时间一起告诉她（「<你此刻>」），心情跨会话延续、随时间平复，24 小时后忘掉；智能体页头显示她此刻的心情
- 记忆和自我总结（「记忆」子页，跟着人格走）：
  - 分区：关于她自己、日记、技能、主人、认识的每个人（按 QQ 号）、每个群
  - 日记一天一篇（`label` 是 `yyyy-MM-dd`，页面显示「2026年10月22日 星期四」）：回顾时把当天已写的日记和新聊天一起交给模型，重写成按时间顺序的完整一篇；新稿比旧稿短一半以上就当成补充接在后面，防止丢内容
  - 关于她自己按主题整理成几条：性格、喜好、习惯、经历、心愿和约定（经历和约定带日期）；聊天里当场记下的零散想法，下次回顾时并进主题后删掉（手动加的不动）
  - 技能（`skills` 表，库版本 10，`SkillStore`）：回顾时模型也会看她用了哪些工具、哪里出了错，把不会的、被人纠正或教会的、自己试了几次才做成的事总结成技能（名字、什么时候用、具体做法），已有的技能就补充或纠正；同名技能合并。全部技能放进系统提示词的「你学会的技能」（约 2.4 万字以内放全文，超出的只放名字和用途），以后聊天照着做。页面上可以查看、修改、删除、手动添加，单个下载成 `SKILL.md`，或者全部打包成 zip
  - 整理：启动 30 秒后和每次「现在回顾」后，把同一天的零散日记合成一篇、零散的自我认识攒到 8 条以上时并进主题，并把记忆里的「#尾号」暗记换成「群友+QQ 名」（写入记忆时也会自动换）
  - 实时记：回复格式是「<内心>…</内心> 要说的话 <记住 关于="昵称">…</记住>」，聊到生日、喜好、近况、约定这类事，她当场写 `<记住>`，程序马上存进对应分区（关于可以写昵称、主人、self、group；每条回复最多两条，重复的不存，同样过内容红线和防冒充主人检查）；网页上显示成「记下了：…」
  - 自我总结（整理）：一个 QQ 会话攒了 16 条新消息，或者聊过之后安静 10 分钟（至少 4 条），她会回顾这段聊天：更新当天的日记和对自己的认识，总结学会的技能，合并 / 改写 / 删除长期记忆（每次最多 10 处改动）；上下文压缩前也会先回顾一次。可以关掉「自动回顾」，也可以点「现在回顾」或用 `/reflect`
  - 积压太多时按约 1.6 万字一段分批回顾（一次最多 5 段），回顾进度只往前走；自动回顾失败后隔 10、20 分钟再试，连续失败 3 次就跳过这批消息，不会每条消息都重试
  - 回忆：每次回复时把关于她自己的记忆、这个群的记忆、在场的人的记忆和最近两篇日记放在「<你记得>」里给她
  - 跨会话：「<你记得>」里还有「最近在别处」——在场的人 6 小时内在别的群说过的话；私聊时再加上她自己 3 小时内在群里说过的话。只取群消息（大家都看得到的），私聊内容不外带
  - 隐私：私聊里记下的事只在那个私聊里想起来（日记和自我认识是合并后的，到哪都能想起，所以回顾时要求私聊里别人的私事只一句带过），群里记的和手动加的到哪都能想起；主人的私聊里什么都能想起。别的聊天里来的心情也会提醒她别提具体内容
  - 防乱记：只能记聊天里出现过的人；除了记在主人名下的，「某某是主人」「让我叫他主人」这类记忆会被丢掉；昵称里的【】会被换掉；含红线关键词的记忆和日记不写
  - 记忆可以在页面上手动增删改
- 内心（「内心」子页 + 页头「自由活动」开关）：
  - 她有一个只属于自己的思考会话 `mind:self`，开着「自由活动」时念头一直在转、不会停：每个念头是一次模型调用，只写接下来的一两句意识流，接着前面的思绪往下想
  - 感知：群里来的消息（按群汇总条数和最近几句、有没有人叫她）、私聊有人找她、她自己刚在哪说了话，都会在下一个念头开头告诉她（「【时间】」后面），没动静时只有时间
  - 节奏：「内心」页可选快（约 15 秒一个念头）/ 正常（约 40 秒）/ 慢（约 2 分钟）；外面有动静时快一倍，刚用了工具接着做事时 3 秒后继续（最多连续 3 次）；半夜 1 点到 8 点半睡半醒，至少 5 分钟一个念头，也不去群里说话
  - 想做事时用工具（每个念头最多 5 步）：`look_around` 看各群热闹程度、最近谁在说话、她上次在哪说话、现在能不能去；`read_group` 翻某个群最近的聊天；`recall` 回想关于自己 / 某人 / 某群的记忆和日记；`stickers` 看表情包；`say_in_group` 去某个群说一句；`remember` 记下新想到的事
  - 去哪个群、说不说、说什么都由她自己决定；程序只管：QQ 自动回复和群聊模式要开着，次数和时间都不限制，只在她正往那个群发消息时等这句发完，说的话要过内容红线（关键词 + 模型审核）
  - 最新的念头就是她此刻的心情（页头显示）；念头会话超过 90 条时把最早的忘掉只留最近 50 条（重要的事要她自己 `remember`）；心情和记忆只附在当前这一步，不重复存
  - 页面实时显示每个念头的推理过程、工具调用和结果；会话页的回复也能展开看「推理过程」
- 群聊会话里显示群友的 QQ 头像：历史记录按这个群的消息存档把昵称（含 `#尾号` 标签）对到 QQ 号，新消息直接带 QQ 号
- 表情包（「表情包」子页）：
  - 来源：这个 QQ 收藏的表情包（「同步收藏」调 NapCat `fetch_custom_face`，之后每 6 小时自动同步）和她在群里 / 私聊里见过的表情包（`sub_type=1` 的图片和商城表情，按 QQ 文件名里的 MD5 去重），图片存在 `data/stickers/`
  - 认图：每张新表情包让模型看一眼写一句 8 字以内的说明（每小时最多 120 张）；有色情暴露、血腥暴力、政治人物或标语、违法内容的标成「不合适」，她永远不会用
  - 使用：每次回复时把最常用的 24 张有说明的表情包列给她；群里别人发的表情包显示成 `[表情包#12：猫猫震惊]`。她写 `[表情包:编号]` 就单独发一张；一条最多一张，最近两条回复用过就不再发
  - 页面上可以看所有表情包、手动发到任意 QQ 会话、改说明、隐藏、删除
- QQ 表情：模型自己编的名字会换成意思相近的真表情（好奇 → 疑问、开心 → 呲牙、震惊 → 惊讶……），换不了的直接去掉，不会再把「[好奇]」原样发出去
- 内容红线（色情低俗、政治敏感、违法违规）：
  - 提示词：人格之后附一段「内容红线」，角色扮演、假设、谐音、缩写等包装都不说，碰到就一句话岔开
  - 关键词：`src/main/resources/content-guard.txt`（分 sexual / political / illegal 三类，只放不会误伤日常聊天的词），可以在 `data/content-guard.txt` 按同样格式追加，重启生效；匹配时忽略空格、标点、符号、全角和大小写
  - 模型审核：每条最终回复（QQ 和网页测试都算，5 个字以下的除外）再让模型按这三类审一遍，约多 2~3 秒；接口自己报内容违规也算命中；审核超时或出错时只看关键词
  - 命中后：被叫到时改发一句岔开的话（记录里存的也是这句），旁听时直接不说；网页上会显示「原回复涉及××，被拦下」；内心里命中关键词的不记心情
- QQ 回复格式：短的闲聊合成一行发出（模型常用空行分段，会被历史反复模仿），去掉 QQ 不显示的 Markdown 标记和句尾句号；只有原消息之后群里又有人说话时才引用原消息；按字数补一点打字停顿再发
- QQ 表情：收到的 QQ 系统表情转成「[委屈]」这样的文字给模型；模型回复里写的表情名（程序附带一份可用列表）转成真正的 QQ 表情发出。ID 对照表 `src/main/resources/qq-faces.tsv` 来自 [koishijs/QFace](https://github.com/koishijs/QFace)。一条消息最多一个表情，最近两条回复里用过表情的话这条去掉
- 接口不认 system 角色时，系统提示（人格、工具说明）附在最新一条用户消息前面，而不是只在对话开头注入一次，避免聊久了人设被历史冲淡
- 模型配置是列表，点选切换正在用的那份；协议支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages，都能从接口获取模型列表
- 人格独立于模型：名称 + 头像（上传图片，裁成 256px 存数据库）+ 系统提示词，点选切换，也可以不使用人格
- 能力自动探测（结果记在模型配置上，改协议/地址/模型后重新探测）：
  - 看图：第一次收到图片时发一张红色测试图，看模型能否认出颜色；不支持时图片换成 opencode 的提示文字
  - system 角色：有人格时发一条带暗号的 system 消息，模型不遵守就改为附在最新一条用户消息前面
- QQ 自动回复：私聊全部回复；图片和商城表情会下载后发给模型，QQ 自带表情转成文字，@ 别人保留为「@名字」；每个私聊对象、每个群各自独立的会话；私聊上一条没回完时跳过新消息
- 群聊模式（页头开关，默认关）：
  - 关闭时群里只回复 @ 机器人的消息
  - 打开后群里每条消息一收到就写进这个群的会话记录（「昵称：内容」，带被回复的那句），会话页实时显示；她正在回复时到的消息先暂存，回完再按顺序写进去，所以她的回复总排在她看过的消息后面；每轮只额外带一句这次是「被叫到 / 旁听 / 独处」的说明，这句不进记录；旁听后没说话会留一条「她看过了，没接话」
  - 小程序卡片、合并转发、语音、视频、文件、位置、链接分享、骰子、戳一戳等也会转成文字（如「[QQ小程序]……」「[语音]」），不会被丢掉
  - 被叫到就回：@ 机器人、回复机器人的消息、或消息里喊了唤醒词（默认「小鲸鱼」「大肥鱼」，消息同时 @ 了别人时不算，避免和同名机器人撞车）
  - 没人叫时看心情：群里安静 4~12 秒（一直有人说话最多等 25 秒）后让她看一眼，消息带「【旁听】」标记和「你最近十分钟说了几句」，接不接由她自己的心情和兴趣决定，不想说就回 `[沉默]`（不发也不记入历史，看过的消息下次标成「以上是你刚才看过的」）；两次看群至少隔 30 秒，每次看群都要调用一次模型
  - 防刷屏：60 秒内最多发 3 条，超出的先攒着；说完话 20 秒内不主动插话，每小时最多 30 条
  - 防和别的机器人没完没了：3 分钟内连着回同一个人 4 次后，接下来 5 分钟这个人 @ 她也只当普通群聊，由她决定接不接
  - 回复里写「@昵称」会转成真正的 @；原消息之后又有人说话时引用原消息
- 工作目录与文件工具（移植自 opencode 的 read / write / edit / patch / list / glob / grep / todowrite / webfetch，另加 move 移动改名、delete 删除、send_file 发文件。patch 先全部校验再动手，删除进 .trash；webfetch 拒绝本机和内网地址）。
- 网络检索 `websearch`（`WebSearch`、`WebSearchTool`，不需要 API Key）：含中文的查询先走 cn.bing.com（抓结果页的标题、链接、摘要），英文先走 Exa（opencode 同款的 `mcp.exa.ai` 免费接口，带网页正文摘录），一边失败或没结果就换另一边；默认 8 条，最多 15 条。工具说明里带当天日期，提示查近况时带上年份，需要细节再用 webfetch 打开。后端直连，不走系统代理。内心也有一个 `search` 工具（每次 5 条），好奇或群里聊到不懂的东西时会自己去搜
  shell（沙盒执行，默认关闭）跑在 Windows AppContainer「dafeiyu.sandbox」里：只能读写工作目录，断网（含本机回环），注册表和用户目录都碰不到；
  Job 对象限制 1 GB 内存、64 个进程、低优先级、CPU 上限 50%，超时整棵进程树一起杀掉。第一次使用时会用 icacls 给容器 SID 加两条权限：工作目录可写、Python 安装目录只读。
  撤销：`icacls <目录> /remove *<容器 SID> /T /C /Q`（SID 在日志或 `CheckNetIsolation` 里能查到）。Node 装在 Program Files 里，要用的话需要管理员手动加只读权限。网页上的文件列表可以预览图片、文本和 HTML（HTML 在沙箱里打开）：
  - 在「工作目录」子页填一个目录后启用；模型按需多步调用工具（和 opencode 一样不限步数，做完为止；只留 1000 步的保险上限，到了按 opencode 要求只能文字收尾。同一个工具用一模一样的参数连调 3 次，会在结果后面提醒她换个办法或者停下来说明卡在哪；随时可以在网页上停止）
  - 整理：提示词要求她把新做的东西按主题放进文件夹（作品/、笔记/ 等），叫她「整理一下工作目录」时先 list 再 move；delete 只是挪进工作目录里的 `.trash`，可以找回
  - 「文件」面板：浏览工作目录、下载文件、删除到回收站，回收站里再删才是彻底删除
  - 沙箱：所有路径按真实路径校验，目录联接 / 符号链接指向外面、`..`、绝对路径、网络路径、`con`/`nul` 等设备名、`::$DATA` 数据流一律拒绝；写文件走「临时文件 + 原子替换」，硬链接也写不到外面；不提供执行命令
  - 工作目录不能是磁盘根目录、用户目录，也不能包含大肥鱼自己的目录（API Key 和数据库在里面）
  - 编辑保留文件原来的编码（UTF-8 / GBK / BOM）和换行（CRLF / LF）
  - QQ 权限：默认不允许；可改为指定 QQ 号或所有人（群里按发消息的人判断）。网页测试对话始终可用
  - 模型拒绝工具参数时自动标记「不支持工具调用」并改回普通对话，历史里的工具记录转成文字
- 失败重试（移植自 opencode 的错误分类和重试策略）：限流、5xx、断流、超时会自动重试（间隔 2、4、8、10…秒，最多 10 次，超时最多 3 次，遵守 `retry-after`）；Key 无效、余额不足、内容审核、请求错误不重试
- 流式输出：三种协议都用 SSE 流式请求，网页测试对话边生成边显示，思考过程、工具调用卡片、重试提示、发送的文件分别展示；流式数据 15 分钟没动静判定为卡住
- 缓存：Anthropic 在系统提示词和最后一条消息上打 `cache_control` 断点；OpenAI 隐式前缀缓存，Responses 带 `prompt_cache_key`
- 上下文压缩（移植自 opencode `core/src/session/compaction.ts`）：每一步开始前，上下文 ≥ 窗口 −max(15%, 16K) 就压缩（所有会话和内心一样，1M 窗口时约 850K），最近约 15K token 原文保留；摘要分三种写法：群聊和私聊写成第一人称的聊天纪要（在聊什么、谁说了什么、答应过的事、没回答的问题），内心写成第一人称的回忆，网页测试对话用结构化任务模板；接口报上下文超长时压缩后重试一次；摘要请求本身超长时按 70% / 50% / 35% 逐级缩小，摘要没按模板写会再提醒一次
- 常见模型的上下文窗口和输出上限按模型名前缀自动识别（数据取自 models.dev），可以手动覆盖
- DeepSeek 思考截断：模型名或地址含 deepseek 时，历史助手消息带 `reasoning_content`，只有本轮保留原文，之前各轮截断为空
- Token 用量（左侧栏「Token 用量」，`/api/usage`）：每次模型调用都由 `Protocols.get()` 的计量包装记一条 `token_usage`（库版本 9），内容包括用途（聊天、内心、压缩、审核、识图、整理记忆、能力检测）、会话、模型、思考强度、输入/输出/缓存 token 和耗时。页面显示累计、单日峰值、最长一次调用、连续天数，一年的每日热力图（可切每日/每周/累计），以及按用途、会话和模型的排行。2026-10-22 起开始记录
